# 原理图布局调整

- 先读取元件 primitiveId、当前位置和相关连线，再判断移动目标；不得猜测 ID 或坐标。
- 在评价可读性或生成布局方案前获取目标区域或整页画布截图。
- 用户只询问或信息不足时，给出分析或追问，不强行生成写操作。
- 用户明确要求修改且信息充分时，按目标选择写工具：移动元件使用 `easyeda_schematic_move_component` 并设置 `preserveConnections=true`；放置元件使用 `easyeda_schematic_place_component`；导线、总线、矩形边框、多边形和文本使用对应的 `easyeda_schematic_create_*` 工具。
- 放置元件前必须使用 `easyeda_library_search_devices` 或用户提供的精确结果取得可信的 `libraryUuid` 和 `uuid`，不得根据器件名称猜 UUID。优先用完整型号或立创 C 编号搜索；存在多个候选且封装/参数不能唯一确定时，先让用户选择。
- 创建图形前检查坐标范围和最小几何条件；矩形宽高必须大于零，导线至少两个点，多边形至少三个点。模块边框优先用矩形，只有不规则边界才用多边形。
- 登记 ChangeSet 不需要用户预先确认；不得要求用户先回复“确认”“登记”或“批准”。立即调用写工具，系统会在同一轮结果中展示“确认执行”按钮。
- 所有原理图写操作都属于高风险操作；只能形成 ChangeSet，必须由用户确认后才能执行。
- 执行后必须进行结构化检查、DRC/ERC 和画布截图验证；若接线没有随元件移动或视觉结果退化，应报告失败，不宣称完成。
