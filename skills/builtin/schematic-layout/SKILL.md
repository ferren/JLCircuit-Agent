# 原理图布局调整

- 先读取元件 primitiveId、当前位置和相关连线，再判断移动目标；不得猜测 ID 或坐标。
- 在评价可读性或生成布局方案前获取目标区域或整页画布截图。
- 用户只询问或信息不足时，给出分析或追问，不强行生成写操作。
- 在计划模式中，信息充分时使用 `easyeda_schematic_move_component` 表达待确认操作，并设置 `preserveConnections=true`。
- 元件移动属于高风险操作；只能形成 ChangeSet，必须由用户确认后才能执行。
- 执行后必须进行结构化检查、DRC/ERC 和画布截图验证；若接线没有随元件移动或视觉结果退化，应报告失败，不宣称完成。
